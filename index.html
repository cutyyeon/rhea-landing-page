AUTOLOGOUS PRP SYSTEM

RHEA

Autologous Bioactive Molecules Enrich System

환자 자신의 혈액에서 생리활성물질(PRP)을 자동으로 분리·농축하는 자가유래 재생치료 시스템입니다. 6,500 RPM 정밀 원심분리와 자동 센서 감지로 안전하고 일관된 결과를 제공합니다.

제품 문의하기 카탈로그 다운로드

PRODUCT OVERVIEW

혈액 처리용 의료기기

이 제품은 '의료기기'이며, 사용상의 주의사항과 사용방법을 잘 읽고 사용하십시오.

PRP 프로토콜 선택

USAGE PROCESS

간편한 6단계 프로세스

01

혈액 채취

환자에게서 60ml의 전혈을 채취하여 항응고제가 든 혈액백이나 주사기에 담습니다.

02

프로토콜 선택

Protocol A(PRP 3ml) 또는 Protocol B(PRP 6ml) 중 원하는 프로토콜을 선택합니다.

03

키트 장착

화면 안내에 따라 일회용 키트, 주사기, 혈액백을 장착합니다.

04

혈액 주입

시작 버튼을 클릭하면 혈액 펌프가 혈액백/주사기의 혈액을 원심분리 용기로 보냅니다.

05

원심분리 시작

6,500 RPM 속도로 약 3분간 정밀 원심분리를 진행합니다.

06

PRP-PPP 수집

센서가 목표 세포(PRP)를 감지해 PPP와 PRP를 각각 주사기에 자동으로 수집합니다.

CORE TECHNOLOGY

RHEA의 3가지 핵심 기술

고속 정밀 원심분리

6,500 RPM 정밀 제어 원심분리로 세포 손상을 최소화합니다.

자동 센서 감지

목표 세포(PRP)를 자동으로 감지하여 손실 없이 분리합니다.

프로토콜 커스터마이징

PRP 3ml / 6ml 중 원하는 프로토콜을 선택할 수 있습니다.
